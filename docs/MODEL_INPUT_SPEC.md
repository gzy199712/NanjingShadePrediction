# 模型输入规范

每个训练样本由 `point_id + date + hour` 唯一确定。

| 输入 | 形状 | 说明 |
|---|---:|---|
| 方向 DINOv2 特征 | 8 × 768 | 八个方位窗口的视觉表征 |
| 全局 DINOv2 特征 | 768 | 街景整体视觉表征 |
| 语义与结构特征 | 27 | 天空、建筑、植被、道路等比例及结构指标 |
| 动态条件 | 11 | 气象、太阳几何和辐射变量 |

模型直接输出遮荫率和 Tmrt；UTCI 由预测 Tmrt 与气象条件通过标准公式计算。数据按点位和日期隔离为训练、验证和测试分区，标准化参数只在训练分区拟合。五个随机种子模型的均值作为最终预测，标准差表示模型分歧，不作为严格统计置信区间。
